# Пакети

Satellite Connect складається з одного основного пакета, незалежного від мереж (**L3**), і трьох пакетів **L4**: по одному адаптеру для кожної платформи блокчейнів (EVM, Solana), побудованому на основному пакеті, і прив’язок React для його сховища. Встановіть основний пакет і лише ті пакети L4, які потрібні вашому застосунку. Усі пакети оголошують свої Web3-бібліотеки та бібліотеки стану як peer-залежності, тож ваш застосунок тримає лише одну копію `zustand`, `immer`, `viem`, `@wagmi/core`, `@solana/kit` чи `react`.

Сторінка кожного пакета починається з README пакета (того самого тексту, що опубліковано в npm), за яким іде повний список його експортів. Сторінку кожної функції, типу й константи згенеровано з вихідного коду TypeScript та його JSDoc, тож довідник завжди відповідає випущеному коду. README пакетів і довідник подано англійською. `@tuwaio/satellite-react` має три точки входу (`@tuwaio/satellite-react`, `@tuwaio/satellite-react/evm` і `@tuwaio/satellite-react/solana`), описані як окремі модулі.
